### 抓包环境警告

不加过滤时，回环接口上会混入大量**无关后台流量**（实测看到 59511、6406、32054 等端口，
其中 59511 是 DSH Web GUI 自己在通信）。所以：

- 一律用 `tcp.port == <你的端口>` / `udp.port == <你的端口>` 过滤；
- 不要只用裸 `tcp` / `udp`，更不要用协议名过滤（非知名端口会显示成 LLC）。
